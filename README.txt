    TELEGRAM ACCOUNT MANAGER BOT
═══════════════════════════════════════════

УСТАНОВКА:
──────────
1. Установи Python 3.10+
2. pip install -r requirements.txt

НАСТРОЙКА:
──────────
1. Иди на https://my.telegram.org
   → войди → API development tools
   → создай приложение
   → скопируй api_id и api_hash

2. Создай бота у @BotFather → /newbot
   → скопируй токен

3. Открой config.py и вставь:
   BOT_TOKEN = "токен от BotFather"
   API_ID = твой_api_id
   API_HASH = "твой_api_hash"

ЗАПУСК:
───────
python bot.py

═══════════════════════════════════════════
ФУНКЦИИ БОТА:
═══════════════════════════════════════════

➕ Добавить аккаунт
   → вводишь номер → код → пароль (если есть 2FA)
   → сессия сохраняется

📂 Загрузить .session файл
   → отправь .session файл (Telethon формат)

📋 Мои аккаунты
   → список всех аккаунтов
   → выбери аккаунт для управления

На каждом аккаунте:
   ✏️ Имя      — меняет имя/фамилию
   📝 Био      — меняет описание профиля
   🔤 Юзернейм — ставит юз + 2 случайных символа
   🖼 Аватарка  — меняет фото профиля
   🚪 Кик сессий — выбивает все посторонние сессии
   🧹 Очистить  — удаляет контакты, чаты, каналы

🔧 Массовые действия — то же самое сразу на всех аккаунтах

═══════════════════════════════════════════
ВАЖНО:
   Сессии хранятся в памяти.
   После перезапуска бота нужно добавить снова.
   Для постоянного хранения добавь базу данных (SQLite).
